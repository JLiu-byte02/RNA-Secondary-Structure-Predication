# LONG-50-v1：B0 与 E 系列长轮数比较

固定 TR0 10,682 条训练、VL0 1,286 条验证，TS0 1,288 条和 bpRNA-new 5,388 条测试；所有方法均使用种子 17、23、41。B0 为原 PairHead（175,553 参数），E0/E1/E2 为 PairHead 加纠错 CNN（186,306 参数）。同一种子的四组 PairHead 初始化逐张量一致。RiNALMo 始终冻结；B0 不使用 P、Q 或距离信息。

固定完整 50 轮，不执行提前停止。预先比较 10、20、30、40、50 轮预算，不依据测试结果增加预算或改动超参数。AdamW、lr=1e-4、weight decay=1e-4、batch size=1、累积4、clip=1、BF16 及原有候选 BCE 和完整真值 F1 保持不变，不额外引入学习率调度器。因本阶段关闭提前停止，历史 patience=3 的 10 轮上限结果单列，不能把两种停止策略混为一谈。

E 系列从本项目此前同一种子的最后一个完整 epoch 和 AdamW 状态接续，保留并校验已有 epoch 文件。逐一重新前向计算已有 epoch 的 VL0 指标，要求原阈值网格 F1 精确复现，再补充缺失的诊断指标。旧 E2/seed23 在9轮早停，因此本阶段从第10轮继续。B0 从随机初始化训练完整50轮。不得从此前最佳 checkpoint 重启后将轮数简单相加。旧目录保持只读。

每轮记录在线训练 BCE、VL0 评估 BCE、完整真值 RNA-macro P/R/F1、固定0.5概率阈值下的候选配对 accuracy 和 balanced accuracy、训练与验证耗时。候选 accuracy 的负类比例很高，仅作为辅助诊断；主指标是结构解码后的完整真值 exact F1。在线训练 BCE 是参数不断更新时的均值，VL0 BCE 使用轮末参数，二者不能直接相减当作精确泛化间隙。

各预算仅在前 N 轮中按 VL0 F1 选择 checkpoint，epoch并列取较早者、阈值并列取较小者。每种方法/预算再以三种子平均 VL0 F1 选择一个共同阈值。全部12条训练轨迹完成后，统一锁定60个方法/种子/预算选择，再运行固定测试集。测试分数仅用于描述这五个预定预算的结果，不用于挑选训练预算或修改模型。相同 checkpoint、阈值和集合的重复组合可复用完全相同且校验 SHA256 的预测文件，报告明确实际独立前向次数。

收敛指标预定义为达到本轨迹最大 VL0 F1 的95%所需 epoch/累计训练时间，以及首次距最大值不超过0.001的 epoch/时间。过拟合通过原始逐轮 VL0 F1 从峰值的回落、VL0 BCE 上升及训练损失下降联合观察；同时画出最佳值曲线，说明其单调性来自 checkpoint 选择规则。报告提供逐种子数据、三种子均值和样本 SD，不将 SD 称为置信区间，不以三个种子宣称统计显著性。

时间分别记录继承轨迹的训练成本、本阶段新增训练成本、验证诊断与实际作业时间。共享集群的排队与节点负载会影响总墙钟时间，不能用排队时间推断方法计算效率。比较训练开销时统一使用每轮训练段和累计训练段耗时，并披露前缀复用。

输出隔离于 `outputs/long_epochs/`，配置为 `configs/long_epochs.yaml`。训练源代码按实际运行依赖建立不可变指纹和逐文件快照，图表/报告代码可独立迭代；正式训练的数值代码不能在轨迹中途更改。

图表契约：问题为“延长预算的验证/测试收益能否抵消时间成本，B0 与 E 系列有何差异”。使用 Python、量化图组：逐轮验证曲线呈现收益及回落，损失曲线诊断优化与过拟合，预算测试图验证泛化，时间—性能图描述成本。源数据为完整逐轮 CSV 与固定预算 CSV，中心为三种子均值、阴影/误差为样本 SD；保留全部种子和全部轮次。报告用途，输出可编辑 SVG/PDF 与 PNG 预览，最终字号至少7pt，并做排版、PDF字体与碰撞检查。
