本轮按用户于2026-10-22确认的设置执行：保留原 E0/E1/E2、冻结通用 RiNALMo-Giga 表征、训练50轮；仅替换为 RiNALMo 使用的 ArchiveII 九折数据。此前已取消的逐步解冻实验及监督训练结果不参与本轮。新输出目录为 `outputs/archiveii_frozen/`，新模型从原始随机预测头初始化，不继承 TR0、旧 ArchiveII 或其他家族折的监督参数。

## E训练保持原设置

三种子17、23、41；同一折、种子的三方法具有完全相同的完整预测头初始化和训练/验证ID。E模型为现有 `ThermoFusion`（186306个可训练参数），直接复用原来的 `train_epoch`、模型、BCE及解码代码。RiNALMo通用权重SHA256固定为 `cd93c3f21eb3e767373c9491192686b5846247bd1110693e453c1dd0f321c0db`。重新生成冻结最后层表征，去CLS/EOS、BF16推理、FP16存储；监督训练不加载语言模型，只加载这些不需要梯度的表征。

AdamW、学习率1e-4、weight decay1e-4、batch1、梯度累积4、梯度裁剪1.0、CUDA BF16预测头计算、FP32参数及优化器状态。固定50轮，无早停，无新增学习率调度。保持原候选配对BCE，仅典型配对且间距≥4参与损失；完整原始CT真值用于结构指标。P/Q来自序列自身ViennaRNA2.6.4 Turner2004、37°C，同一次partition function及真实stack联合概率，不使用CT标签产生特征。E0不读取P/Q，E1读取P，E2读取P/Q。

每条轨迹保存所有50轮检查点、AdamW与Torch/CUDA随机状态，按最近具有完整验证记录的检查点恢复。每轮shuffle沿用 `Random(seed*1000+epoch)`。选模也保持原设置：在50轮内选择验证集完整真值RNA-macro exact F1最高的epoch，平分取最早轮；阈值网格0.1–0.9步长0.1；同家族、方法的三个所选检查点共同选择使平均验证exact F1最高的一个阈值，平分取较低值。全部81个E选择统一锁定后才提交E测试，不用留出家族的分数决定超参数、方法或预算。各家族按表中顺序进入队列，独立轨迹可在Slurm分配的GPU上重叠执行。

## 两种模型的对比含义

[RiNALMo论文](https://doi.org/10.1038/s41467-025-60872-5) 的基线是编码器经过逐步解冻微调、配原生预测头的模型。本轮使用 [官方公开的九个家族微调检查点](https://zenodo.org/records/15043668)，核对公开MD5和本地SHA256，加载各检查点保存的阈值，在同一测试CT上重新推理和评估。其原生模块及FP16推理遵循官方实现，指标与解码参考源码保持原字节，许可证一并保留。

因此两种模型使用相同的官方下游划分和测试样本，但编码器训练状态、预测头架构、损失及阈值搜索策略不同。这是按用户要求保留原E训练方法的模型对比；不能把差值全部归因于纠错模块。E1/E2相对E0的同种子配对差值用于衡量额外热力学信息的作用。官方每家族一个发布模型，与E的三种子均值±样本SD分开表示，不虚构官方基线的种子方差。

主比较指标为官方默认允许单个配对端点±1nt偏移的逐RNA F1，再在家族内平均；同时报告完全精确的P/R/F1。对空真值与空预测，官方口径返回0，原E选模函数返回1；分别保留并在结果中记录实际空真值数。最终从每条预测对照完整CT真值，调用未修改的官方矩阵函数独立复算两种口径。

九家族主汇总对家族等权：先对每家族RNA平均，再对9家族平均。另报按3865条RNA加权的总体均值。E的汇总SD先对每个共同种子求9家族均值，再对3个种子算样本SD；不把家族间差异当成种子误差。Family-OOD描述监督训练与测试的家族分离；通用预训练语料没有在本项目重新按家族排除。

## 执行与证据

数据、P/Q和表征先单独准备；真实GPU smoke检查三方法梯度、共同初始化和最长训练RNA。正式训练前发布源代码并封存数据、源码和配置哈希。Supervisor限制任务队列长度，记录每个Slurm作业及失败/重试，不改动其他实验或其他用户进程。大权重、缓存、检查点和逐RNA预测保留在服务器，代码与压缩审计清单及结果报告同步GitHub。

```bash
source activate.sh
python scripts/archiveii_frozen_data.py --download --prepare --cache --workers 8

sbatch slurm/smoke_archiveii_frozen.sbatch
nohup python -u scripts/reproduce_archiveii_frozen.py > logs/archiveii_frozen_cluster.log 2>&1 < /dev/null &
```
