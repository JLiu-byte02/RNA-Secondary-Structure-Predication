# 下一阶段：从配对门控到结构编辑选择

状态：依据本阶段诊断形成的研究方案，尚未训练选择器，尚未实施以下新实验。由研究代理按用户授权作出方案选择；不把方案当作用户已经认可的实验结果。

研究问题：在家族转移下，对一个冻结预测器的结构提案，能否学会保留有益的茎/交替配对修改、拒绝有害修改，以较少损伤获得超过充分校准固定融合的效果？

## 方案取舍

| 路径 | 好处 | 局限 / 决定 |
|---|---|---|
| 扩大现有 CNN、训练更多轮 | 改动少 | v1 校准很快平台化，不能解决结构编辑目标错位；不优先投入 |
| 统一校准 + 简单安全编辑规则 | 最便宜，建立强控制 | 创新有限，但必须先做，防止复杂度掩盖弱基线 |
| 结构编辑片段效用选择器 | 直接针对错误修改，可保持匹配合法性 | 真值 oracle 只证明空间存在，学习难度未知；作为下一模型候选 |

先做第二条，再以小规模方式验证第三条。完整微调编码器、LoRA 和更多物理特征暂缓，防止同时改变多个因素。

## 第 0 步：不用重新训练，统一校准现有方法

复用冻结 checkpoint 和基础 logits，对固定融合、残差、global/local/protected gate、R1 强度策略使用相同扩展阈值集合、数据角色、解码器和选择目标。开发集已被研究设计接触，所有结果均标注后续开发；不能包装成新的盲确认。先锁定全部案例和方法的校准选择，再读取开发分数。

对比单一 F1 最优点、校准经验风险约束点及固定预算下的 F1/损伤曲线。报告 exact/flex PRF、每 RNA 损伤数量/比例、F1 退步 RNA 占比、编辑覆盖率，避免单独降低编辑数量带来的虚假安全改善。若普通阈值/强度校准已解释差异，应保留简单方案，不继续堆叠神经网络。

执行实现应先做纯 CPU 解码/校准，必要时一次批量 GPU 推理后缓存；复用缓存，不为每个阈值重新运行网络。资源先限额 1 GPU 小时，CPU 阶段独立记账；未完成前不增加模型训练。

## 第 1 步：片段表示与模型

使用已实现并测试的原子编辑分解：两个合法匹配的对称差形成交替路径/环，将共享碱基的相互依赖编辑置于同一个包，再将相邻茎修改合并。每次接受整包，保证每碱基最多一个配对；不能为了方便删除所有交叉配对。当前代码只实现分解和使用真值的诊断上限，尚无学习选择器。

首先使用少量可解释输入：包中新增/删除对数量、茎长、跨度、基础分数间隔、P 与基础模型分歧、端点熵、交叉关系的变化、周围保留茎的支持。先训练小 MLP 预测每包的 ΔTP、ΔFP 或有益/有害概率；避免一开始加入大型图网络。若这些输入不能超过规则，再考虑增加冻结 RiNALMo 局部表示的池化特征。

选择阶段优化整条 RNA 的效用近似及修改预算，验证其与实际 exact F1/损伤的一致性；独立包的 F1 贡献并不简单相加。训练可以用真实配对构造监督，推理禁止接触真实结构、家族测试标签或 oracle 选择。加入 identity 拒绝全部编辑选项。

## 第 2 步：严格隔离上游模型与效用监督

现有 v1 提案在全部七个非开发训练家族上拟合，不能直接用其训练内错误训练效用选择器，并声称选择器的上游均未见过这些标签。先用廉价、明确的三级家族链做机制原型：

1. 对每个开发家族 D，完全排除 D 和 5S。复用该案例现有 baseB（在七个可用家族中的三个家族 A 上训练），冻结至结束。
2. 其余四个家族按封存的家族名哈希确定两族 B 与两族 C。提案纠错器只在 B 上训练，使用预先固定的 15 轮终点，不用 C 的标签选择提案 checkpoint。基础头和提案权重在后续保持一致，不切换为七家族 full 模型。
3. 只在 C 上产生选择器效用监督。C 按完全相同序列分组划分选择器 fit/cal；base、proposal 从未训练 C。跨角色完全相同序列拒绝，另记录近同源关系，不将精确去重当成完整同源隔离。
4. 选择器 epoch/阈值/预算仅用 C-cal；所有候选封存后评分 D。每种控制使用同一个基础头、提案、候选包、训练标签预算和校准 RNA。

这会牺牲基础头训练数据量，适合验证因果机制，不能直接与使用七族 full 头的旧表公平比较。若正向，再进行外层专属嵌套/交叉拟合以充分利用训练数据，重新估算成本。C 上校准仍不保证任意 D 分布的风险界，不作形式安全声明。

## 必须一起运行的基线和消融

| 类别 | 对照 |
|---|---|
| 简单分数融合 | 相同扩展网格的 base、P、fixed mix、global/R1 gate |
| 编辑选择 | 全接受、全拒绝、基础分数 margin 规则、保留高置信茎规则 |
| 学习控制 | 参数数量相近的独立配对 MLP、原子包 MLP、茎合并包 MLP |
| 特征 / 训练机制 | 去掉 P、去掉拓扑特征、训练内监督 vs 上游未见家族监督（明确标注前者的依赖） |
| 物理参考 | 固定 MFE/MEA，披露非交叉限制；额外 gamma 扫描须同预算单独记录 |

所有模型报告校准耗时、推理耗时、峰值显存、可训练参数及实际 Slurm GPU 时间。只要结构包模型优势能由 margin/茎保护规则解释，就不把 MLP 复杂度当作贡献。

## 资源与停止标准

本方案不触发新作业。后续先完成第 0 步，再预注册机制原型，额外训练先限 2 GPU 小时、种子 17、两个开发家族。应先 smoke 实测吞吐再确认能否在限额内完成；失败也计费。开发门槛继续要求相对充分校准的最强匹配简单对照，平均 F1 至少 +0.005、单族退步不超过 0.01，并减少实际损伤，而非只减小 gate。未过门槛即停止扩展。

只有通过后才锁定模型、做 17/23/41 三种子及后续设计已接触的九折基准；不能把三种子当作九个独立研究设计。更强投稿证据另需外部集、第二预测头/编码器、同源/预训练暴露说明。5S 在当前方法开发中仍保留，但历史实验已接触整个 ArchiveII。

## 潜在论文贡献的成立条件

潜在主张是“可迁移、保持结构合法性的选择性编辑，在家族偏移下更少破坏基础预测”，而不是泛称“热力学融合”。需要证明：结构包优于配对/标量规则；隔离上游监督的训练机制确有作用；收益跨家族、种子、预测头及外部数据仍成立。当前 oracle 诊断和门控负结果只提供动机，不足以证明这些主张，也尚未完成全面相关工作检索。
